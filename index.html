What the script does, in the order it does it

  1. 01
    Parse the command line

    argparse takes one required argument: the path to the text file, so the call reads like plain shell: python summarize.py document.txt.

  2. 02
    Read the file

    Python's built-in file handling loads the document into a string. A missing or empty file stops here with a clear message instead of a wasted API call.

  3. 03
    Build one strict prompt

    The system prompt casts the model as an expert editor and demands a summary of exactly three bullet points. The file content rides along as the user message.

  4. 04
    Print the summary

    The API response comes back and lands in the terminal, formatted and clean. dotenv keeps the API key in .env, out of the code.

Run it yourself

Three dependencies, one environment file. The key never enters the script: dotenv loads it from .env at runtime, and the file stays in .gitignore.

Works with the OpenAI API or Google's Gemini API: only the request call changes, the pipeline stays the same. 

pip install openai python-dotenv
